# 성경 타워 게임 🏗️📖

기존 타워 게임을 성경 모드로 변경한 프로젝트입니다.

## 🎮 게임 특징

### 모드 선택

- **구약 성경 모드**: 39권의 구약 성경으로 타워 쌓기
- **신약 성경 모드**: 27권의 신약 성경으로 타워 쌓기

### 게임 플레이

1. 게임 시작 시 구약/신약 모드 선택
2. 성경책 블록이 순서대로 등장 (창세기부터 또는 마태복음부터)
3. 각 블록에는 성경책 이름이 표시됨
4. 완벽한 착지 시 금색 효과 추가
5. 게임 종료 시 쌓은 성경책 수에 따른 축하 메시지

## 🛠️ 기술적 변경사항

### 1. 모드 시스템

- `gameMode`: 'old' (구약) 또는 'new' (신약)
- `maxBooks`: 모드별 최대 성경책 수 (39권/27권)

### 2. 이미지 시스템

```
기존 → 변경
c1-c8.png → old-bg-1~8.png, new-bg-1~8.png (배경)
f1-f7.png → old-flight-1~7.png, new-flight-1~7.png (비행 오브젝트)
block.png → old-book-1~39.png, new-book-1~27.png (성경책 블록)
```

### 3. 블록 렌더링

- 성경책 순서에 따른 이미지 표시
- 블록 중앙에 성경책 이름 텍스트 오버레이
- 완벽한 착지 시 금색 효과

### 4. UI/UX 개선

- 모던한 모드 선택 화면
- 그라데이션 배경과 호버 효과
- 반응형 디자인 지원

## 🚀 실행 방법

1. **의존성 설치**

   ```bash
   npm install
   ```

2. **빌드**

   ```bash
   NODE_OPTIONS="--openssl-legacy-provider" npm run build
   ```

3. **로컬 서버 실행**

   ```bash
   python3 -m http.server 8000
   ```

4. **브라우저에서 접속**
   ```
   http://localhost:8000
   ```

## 📖 성경책 순서

### 구약 성경 (39권)

1. 창세기 → 2. 출애굽기 → 3. 레위기 → ... → 39. 말라기

1. 마태복음 → 2. 마가복음 → 3. 누가복음 → ... → 27. 요한계시록
